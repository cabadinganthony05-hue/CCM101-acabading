# Mission 1: Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic skills needed to work as a cloud infrastructure engineer. The activities focus on accessing a Linux environment, exploring the system, organizing files and directories, documenting technical information, and creating a GitHub portfolio.

## Objectives

* Access and use a cloud-based Linux environment.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Organize files and directories using Linux commands.
* Create and maintain a GitHub repository.
* Document technical work using Markdown.

## Activities Performed

1. Accessed the Ubuntu Linux environment through KillerCoda.
2. Created and logged in to a new Linux user account.
3. Gathered Linux system information.
4. Created and organized directories and Markdown files.
5. Created a public GitHub repository for the Cloud Computing portfolio.
6. Prepared documentation and evidence for the laboratory activity.

## Linux Commands Used

* adduser – creates a new user account.
* usermod – modifies user account settings and groups.
* su – switches to another user account.
* whoami – displays the current username.
* pwd – displays the current working directory.
* hostname – displays the system hostname.
* cat – displays file contents.
* uname -r – displays the kernel version.
* lscpu – displays CPU information.
* free -h – displays memory information.
* df -h – displays disk space information.
* mkdir – creates directories.
* cd – changes the current directory.
* nano – creates and edits text files.
* find – searches for files and directories.

## Skills Learned

Through this activity, I learned how to access and work with a cloud-based Linux environment, create and manage Linux users, navigate directories, collect system information, organize files, use Markdown for documentation, and prepare a GitHub repository for a professional cloud computing portfolio.
