# Reflection

This laboratory activity helped me understand the basic environment used in cloud computing. I learned how to access and work with a Linux system through KillerCoda and how to create and manage a user account.

During the activity, I encountered some challenges while using the KillerCoda Playground. One problem I experienced was that when I stayed away from the Playground for a long time, my terminal session could disconnect or reset. Sometimes, the commands and progress from my previous session were no longer available, and the environment would return to the beginning. This required me to repeat some of the steps and commands.

I also experienced some difficulty when creating and editing Markdown files using the Nano text editor. At first, I accidentally entered incorrect content and had to learn how to exit and edit the file properly. These challenges helped me become more familiar with using the Linux terminal and managing files.

Despite these difficulties, I was able to complete the required tasks by carefully following the instructions and checking my work after every step. I learned how to navigate directories, gather system information, create users, organize files, and document technical information using Markdown.

I also learned how GitHub can be used to organize my Cloud Computing Portfolio. Overall, this activity improved my confidence in using Linux and introduced me to the basic workflow of a cloud infrastructure environment. I learned that patience, careful documentation, and regularly checking my work are important when working with cloud technologies.
