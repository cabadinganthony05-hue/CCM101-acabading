# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding the major components of cloud infrastructure and how compute, storage, networking, and identity services work together.

## Objectives

- Explain the major components of cloud infrastructure.
- Investigate hardware and software resources in a Linux environment.
- Differentiate compute, storage, networking, and identity resources.
- Understand the relationship between cloud infrastructure components.
- Create professional technical documentation using Markdown.
- Continue building a structured GitHub Cloud Computing Portfolio.

## Laboratory Activities

This laboratory includes the following checkpoints:

1. Expand Your Cloud Portfolio
2. Investigate the Cloud Server
3. Identify Cloud Infrastructure Components
4. Research the Major Cloud Providers
5. Design a Simple Cloud Infrastructure
6. Technical Documentation
7. Mission Reflection

- Ubuntu Linux
- Git and GitHub
- Markdown
