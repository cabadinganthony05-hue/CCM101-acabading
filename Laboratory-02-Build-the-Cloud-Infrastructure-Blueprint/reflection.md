# Mission Reflection

This laboratory activity helped me understand how different cloud infrastructure components work together in a cloud environment. For me, the compute resource is one of the most important components because it performs the processing needed by applications and services. It allows users and organizations to run different workloads without depending entirely on physical computers. However, compute resources also depend on networking and storage to function effectively.

Linux plays an important role in cloud computing because it provides a reliable operating system for many servers and cloud environments. It also provides command-line tools that administrators can use to monitor and manage system resources. During this laboratory, I learned how to use Linux commands to check information about the CPU, memory, storage, network, and operating system of a cloud-based server.

Technical documentation is also important before deploying infrastructure because it provides a clear plan and record of the resources and configurations that will be used. It helps reduce errors and makes troubleshooting easier when problems occur. Proper documentation also allows other team members to understand how the infrastructure is organized and managed.

Throughout this laboratory, I learned new skills such as investigating a Linux cloud environment, identifying cloud infrastructure components, and using Markdown to create organized technical documentation. I also learned how to compare similar services offered by AWS, Microsoft Azure, and Google Cloud. Creating a simple cloud infrastructure diagram also helped me visualize how users, networks, compute resources, storage, and the internet are connected.

Overall, my GitHub portfolio improved after completing this mission because it now contains more organized and meaningful cloud computing work. I added technical documentation, infrastructure information, a cloud provider comparison, and a cloud architecture diagram. I also gained more experience using Git commands to manage and upload my work. This laboratory helped me improve both my technical knowledge and my ability to document projects professionally.
