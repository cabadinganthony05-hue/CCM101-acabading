# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform

**Amazon Web Services (AWS)**

### Justification

AWS is a suitable choice for the startup because it provides flexible and scalable cloud services that can support a growing mobile application. The company can start with the resources it currently needs and increase them as the number of users and workload grows. AWS also provides managed services that can help reduce infrastructure management tasks. This makes it a practical option for a startup that needs to control costs while preparing for future growth.

### Recommended Services

1. **Amazon EC2** – For hosting the application's backend and server workloads.
2. **Amazon S3** – For storing application files, images, and other objects.
3. **Amazon RDS** – For managing the application's relational database.

---

## Client B – University

### Recommended Platform

**Microsoft Azure**

### Justification

Microsoft Azure is the most suitable choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure has strong integration with Microsoft's ecosystem, which can make it easier to connect existing systems with cloud-based services. The university can also use Azure to provide scalable infrastructure for its applications and databases. This reduces the need to completely change the technologies that the university already uses.

### Recommended Services

1. **Azure Virtual Machines** – For hosting Windows Server workloads and applications.
2. **Microsoft Entra ID** – For managing user identities and access.
3. **Azure SQL Database** – For hosting and managing relational databases.

---

## Client C – AI Research Company

### Recommended Platform

**Google Cloud Platform (GCP)**

### Justification

Google Cloud Platform is recommended for the AI research company because its main requirement involves Artificial Intelligence and Machine Learning applications. GCP provides services designed for machine learning, data processing, and scalable computing. These capabilities can support researchers when developing, training, and deploying AI models. Its cloud infrastructure can also provide the computing resources needed for demanding research workloads.

### Recommended Services

1. **Vertex AI** – For developing, training, and deploying machine learning models.
2. **Compute Engine** – For running scalable and high-performance computing workloads.
3. **Cloud Storage** – For storing datasets, research files, and machine learning models.

---

## Client D – Global E-Commerce Company

### Recommended Platform

**Amazon Web Services (AWS)**

### Justification

AWS is a suitable platform for the global e-commerce company because it provides scalable and highly available infrastructure for applications serving users in different locations. An e-commerce system can experience changes in traffic, especially during busy periods, so scalable cloud resources are important. AWS also provides services for application hosting, databases, storage, traffic distribution, and global content delivery. These services can work together to support a reliable online shopping platform.

### Recommended Services

1. **Amazon EC2** – For running the e-commerce application and backend workloads.
2. **Amazon RDS** – For managing product, customer, and transaction databases.
3. **Amazon S3** – For storing product images and other application files.
4. **Elastic Load Balancing** – For distributing incoming traffic across application resources.
5. **Amazon CloudFront** – For delivering website content efficiently to users in different locations.
