# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, databases, networking, security, analytics, and application development. It allows organizations to use scalable cloud resources without having to maintain all of the physical infrastructure themselves.

## Global Infrastructure

AWS has a global infrastructure organized into Regions and Availability Zones. Each Region is a separate geographic area, while Availability Zones are isolated locations within a Region. This structure helps organizations deploy applications closer to their users and improve availability and fault tolerance.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create and configure cloud resources, monitor services, manage users and permissions, view service health, and manage billing through the console.

## Four Core Services

1. **Amazon EC2** – Provides scalable virtual computing capacity for running applications and workloads.
2. **Amazon S3** – Provides scalable object storage for files, datasets, backups, websites, and applications.
3. **Amazon RDS** – Provides a managed relational database service that simplifies database setup, operation, scaling, backups, and maintenance.
4. **Amazon VPC** – Provides a logically isolated virtual network where AWS resources can be launched and securely connected.

## Three Advantages

1. **Scalability** – AWS resources can be increased or decreased based on the needs of an application or organization.
2. **Global Availability** – AWS provides infrastructure in many geographic locations, allowing organizations to deploy services closer to their users.
3. **Wide Service Selection** – AWS offers services covering computing, storage, databases, networking, security, analytics, and other cloud requirements.

## Typical Enterprise Use Cases

Enterprises can use AWS for hosting websites and applications, storing and backing up data, managing databases, building data analytics systems, running business applications, and supporting artificial intelligence and machine learning workloads.
