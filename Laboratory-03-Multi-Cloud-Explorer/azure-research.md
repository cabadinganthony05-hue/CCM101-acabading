# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

## Global Infrastructure

Azure has a global infrastructure made up of regions, datacenters, and Availability Zones. This infrastructure allows organizations to deploy applications in different geographic locations and helps support availability, performance, scalability, and data residency requirements.

## Cloud Management Console

The Azure portal is a web-based management console used to create, manage, and monitor Azure resources. Users can manage services, configure resources, view dashboards, search for services, and monitor their cloud environment through the portal. 

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual computing resources for running applications and operating systems.
2. **Azure Blob Storage** – Provides scalable object storage for files, data, backups, and application content.
3. **Azure SQL Database** – Provides a managed relational database service for applications and business workloads.
4. **Azure Virtual Network** – Provides an isolated network environment for Azure resources and can support connections to on-premises networks. 

## Three Advantages

1. **Microsoft Integration** – Azure works well with Microsoft technologies and services, making it useful for organizations already using Microsoft products.
2. **Global Infrastructure** – Azure provides a large worldwide infrastructure that supports scalable and highly available applications. 
3. **Hybrid and Multicloud Support** – Azure provides tools and services that can help organizations connect and manage on-premises, cloud, and edge environments. 

## Typical Enterprise Use Cases

Organizations can use Azure for application hosting, database management, virtual machines, data storage, backup and disaster recovery, business applications, analytics, artificial intelligence, and hybrid cloud environments.
