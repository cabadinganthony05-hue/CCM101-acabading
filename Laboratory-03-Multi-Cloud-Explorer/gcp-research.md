# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, and application development.

## Global Infrastructure

Google Cloud has a global infrastructure organized into regions and zones. Regions are geographic areas that contain one or more zones. This infrastructure allows organizations to deploy applications in different locations and helps provide scalability, reliability, and performance.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud projects and resources. Users can create and configure services, monitor resources, manage permissions, and access different cloud tools through the console.

## Four Core Services

1. **Compute Engine** – Provides virtual machines that can be used to run applications and workloads.
2. **Cloud Storage** – Provides scalable object storage for files, datasets, backups, and other data.
3. **Cloud SQL** – Provides a fully managed relational database service.
4. **Google Kubernetes Engine (GKE)** – Provides a managed Kubernetes environment for deploying and managing containerized applications.

## Three Advantages

1. **Strong AI and Machine Learning Capabilities** – GCP provides services and tools that support artificial intelligence and machine learning workloads.
2. **Scalable Infrastructure** – Its global infrastructure allows applications to scale according to changing workload requirements.
3. **Data and Analytics Tools** – Google Cloud provides services that help organizations store, process, analyze, and gain insights from large amounts of data.

## Typical Enterprise Use Cases

Enterprises can use GCP for application hosting, data analytics, artificial intelligence and machine learning, containerized applications, large-scale data storage, and globally distributed web services.
