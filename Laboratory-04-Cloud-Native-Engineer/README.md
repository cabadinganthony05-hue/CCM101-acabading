# Laboratory Activity 4: Cloud-Native Engineer

## Mission Overview

Laboratory Activity 4 focuses on understanding cloud-native technologies, particularly Virtual Machines and Containers. This activity introduces Docker as a platform used for packaging, deploying, and managing applications efficiently.

Through this laboratory, I learned how containers differ from traditional virtual machines and how Docker simplifies application deployment. I also practiced basic Docker commands, deployed an Nginx web server, and managed the lifecycle of a container.

## Objectives

At the end of this laboratory activity, I should be able to:

- Differentiate Virtual Machines and Containers.
- Understand the purpose of containerization in cloud computing.
- Execute basic Docker Command Line Interface commands.
- Deploy and run a containerized Nginx web server.
- Manage running and stopped containers.
- Document technical procedures using Markdown.
- Maintain an organized GitHub Cloud Computing portfolio.

## Docker Commands Executed

The following commands were used during the laboratory activity:

- docker --version
- docker info
- docker pull nginx
- docker run
- curl http://localhost:8080
- docker ps
- docker stop
- docker start
- docker rm

## Skills Learned

This activity helped me understand the basic concepts of Docker and containerization. I learned how to check the Docker environment, download images, run containers, and manage their lifecycle using the command line.

I also improved my technical documentation skills by organizing laboratory files, screenshots, and explanations inside a GitHub repository.

## Challenges Encountered

One challenge I encountered was understanding the correct sequence of Docker commands. Each command has a specific purpose, so following the proper order was important when deploying and managing the Nginx container.

Another challenge was organizing the required documentation and evidence files. With careful checking of the folder structure and instructions, I was able to maintain a clean and organized repository.
