## Mission Overview

In this laboratory activity, I explored cloud storage technologies and their applications in modern cloud computing. I learned the differences between Block Storage, File Storage, and Object Storage, with a focus on how object storage supports applications that handle large amounts of unstructured data.

Using Docker, I deployed MinIO, an S3-compatible object storage server. I also accessed its web console, created a storage bucket named `client-photos`, and uploaded a sample file to verify that the storage service was working.

This laboratory allowed me to apply my knowledge of Linux commands, Docker containers, and cloud infrastructure through a practical deployment activity.

## Mission Objectives

At the end of this laboratory activity, I should be able to:

1. Explain the differences between Block Storage, File Storage, and Object Storage.
2. Deploy an S3-compatible object storage server using Docker.
3. Access the MinIO Web Console through a web browser using port forwarding.
4. Create an object storage bucket named `client-photos`.
5. Upload a sample file and verify that it is stored successfully.
6. Document the deployment process, commands, and configurations using Markdown.
7. Maintain and expand my Cloud Computing GitHub portfolio.
