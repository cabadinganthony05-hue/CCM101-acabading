# Laboratory Activity 8: The Cloud Security Engineer

**Student:** Anthony Cabading  
**Mission:** Cloud Security Engineer  
**Platform:** GitHub and KillerCoda Ubuntu

## Mission Overview
This laboratory focuses on improving the security of an Ubuntu server through network inspection, firewall configuration, and controlled access to a web application.

## Objectives
- Identify basic cloud security principles.
- Examine network ports and exposed services.
- Configure UFW using a Default Deny policy.
- Allow authorized SSH and HTTP application traffic.
- Document firewall rules and security testing results.
