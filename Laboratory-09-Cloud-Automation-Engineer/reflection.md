## Reflection

Automation is important in cloud computing because administrators often manage hundreds or even thousands of servers. Performing the same task manually on every machine would require considerable time and could lead to inconsistent results. With automation, routine operations such as backups, updates, and maintenance can be performed more efficiently and consistently. It also allows administrators to focus on solving more complex problems.

However, automation also introduces risks. A small mistake in a script could affect many systems if the same command is executed across multiple servers. For example, an incorrect file deletion command could remove important information. This is why testing, reviewing commands, limiting permissions, and monitoring automated tasks are necessary before using them in a production environment.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash scripting involved writing commands that perform actions in sequence, such as creating directories and compressing files. Docker Compose, on the other hand, used a declarative YAML configuration to describe how containers and their services should be configured and started. Both approaches support automation, but they serve different purposes.

Looking back at Laboratories 1 through 9, my understanding of cloud computing has expanded beyond simply storing files or using remote servers. The activities introduced me to cloud infrastructure, Linux commands, containers, networking, security, and automated operations. I now understand that maintaining a cloud environment requires several technical skills working together to support reliable services.

Among the cloud engineering roles introduced in this course, I am most interested in the Cloud Automation Engineer role. Creating a working backup script showed me how a short program can reduce repetitive administrative work. I also found it interesting that Cron can schedule tasks without requiring constant manual action. This experience encouraged me to continue learning Linux scripting and practical automation techniques.

## Conclusion

This laboratory helped me recognize that automation is useful only when it is implemented carefully. Reliable cloud operations depend on both efficient tools and responsible administration.
