## Mission Overview

Laboratory Activity 09 focuses on automating routine server administration tasks through Bash scripting and the Linux Cron scheduling service.

Following the cloud security activities in Laboratory 08, this mission introduces automation techniques that help reduce manual work and improve consistency in cloud operations.

The primary task is to develop a backup script that automatically creates compressed archives of application data and schedules the backup process to run every day at 2:00 AM.

## Objectives

- Understand the purpose of Bash scripting in Linux.
- Identify how variables are used in automation scripts.
- Create a functional automated backup script.
- Configure executable file permissions using chmod.
- Generate compressed backup archives using tar.
- Schedule recurring tasks through Linux Cron.
- Document the automation process and its results.
