## 1. Purpose

This report documents the deployment and monitoring of an Nginx web server running inside a Docker container. It records the HTTP requests sent to the website, the application logs generated by Nginx, and the resource usage observed during the laboratory activity.

## 2. Nginx Container Deployment

The Nginx web server was deployed using Docker with the container name `client-website`. The container runs in the background and maps port 8080 on the host to port 80 inside the container.

Command used:

```bash
docker run -d --name client-website -p 8080:80 nginx
```

The container was checked using:

```bash
docker ps
```

The container's port mapping allows the Nginx website to be accessed through `http://localhost:8080`.

## 3. HTTP Traffic Simulation

The following commands were used to test the Nginx website and simulate visitor requests.

### Successful Request

```bash
curl http://localhost:8080
```

This request accessed the Nginx welcome page and returned its HTML content.

Another request was performed using:

```bash
curl -I http://localhost:8080
```

The server returned an HTTP 200 response, indicating that the request was successful.

### Missing Page Request

```bash
curl http://localhost:8080/hidden-admin-page
```

This request attempted to access a page that does not exist. The server returned an HTTP 404 response, indicating that the requested resource could not be found.

## 4. Application Log Analysis

The following command was used to inspect the Nginx container logs:

```bash
docker logs client-website
```

The logs showed two successful HTTP 200 responses and one HTTP 404 response. The failed request was caused by an attempt to access `/hidden-admin-page`.

### Example of a 404 Log Entry

```text
172.17.0.1 - - [13/Oct/2026:07:25:06 +0000] "GET /hidden-admin-page HTTP/1.1" 404 153 "-" "curl/8.5.0" "-"
```

Application logs are important because they help engineers identify failed requests, errors, and unusual application behavior. They provide useful details for investigating problems and understanding what happened when a user accessed the application.

## 5. Real-Time Container Metrics

The `docker stats` command will be used to monitor the running Nginx container's resource consumption.

Command:

```bash
docker stats
```

The command displays real-time information, including CPU percentage, memory usage, memory limits, and network input/output.

The actual CPU percentage, memory usage, and Network I/O measurements will be recorded after the command is executed and a screenshot is captured.
