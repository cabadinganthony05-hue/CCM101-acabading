# Laboratory 06 – Cloud Deployment Engineer

**Name:** Anthony Cabading  
**Program:** Bachelor of Science in Information Technology  
**Course:** CCM101 – Cloud Computing

## Mission Overview

This laboratory focuses on deploying a multi-tier cloud application using Docker Compose. The infrastructure consists of a Nextcloud application container connected to a MariaDB database container.

## Objectives

- Understand the concept of multi-tier application architecture.
- Create and manage a Docker Compose configuration.
- Deploy multiple containers as one application stack.
- Understand the relationship between an application container and a database container.
- Document the deployment process and results.

## Checkpoints Completed

- Checkpoint 1 – Expand Your Cloud Portfolio
- Checkpoint 2 – Research: Multi-Tier Architecture
- Checkpoint 3 – Write the Infrastructure Code
- Checkpoint 4 – Deploy the Multi-Container Stack
- Checkpoint 5 – Access the Private Cloud
- Checkpoint 6 – Technical Documentation
- Checkpoint 7 – Mission Reflection

## Skills Learned

Through this laboratory, I will practice container orchestration, Docker Compose configuration, multi-tier architecture, database connectivity, and cloud infrastructure documentation.
